Implementation Notes

  • Functional Strategy Implementation:
    • Use pure functions with `SearchStrategy` type signature
    • Each strategy is a function that takes query and context, returns results
    • Search registry manages strategy registration and lookup
    • Composition utilities allow combining strategies with higher-order functions
    • Easy to add new strategies by creating new functions
  • Performance Considerations:
    • Use debounced search input to avoid excessive API calls
    • Implement result caching for repeated searches
    • Limit initial results and implement pagination
    • Use React.memo for search result components
  • User Experience:
    • Provide clear loading states and empty states
    • Show search strategy descriptions to help users choose
    • Highlight matching text in search results
    • Allow quick navigation to verses from search results
  • Data Structure:
    • Search results include verse reference, text, and match positions
    • Support for both NIV and KJV translations
    • Include relevance scores for result ranking
    • Group results by book/chapter for better organization

Project Overview

This is a Bible study mobile application that helps users study the Bible with friends. The app provides features for reading, memorizing, and discussing Bible verses.

Key Features

  • Bible Reading:
    • Multiple Bible translations (KJV, NIV)
    • Interlinear Bible with Strong's Concordance
    • Greek and Hebrew lexicon integration
    • Verse-by-verse reading with word highlighting
  • Memory Verses:
    • Save and track memory verses
    • Practice reciting verses
    • Progress tracking and statistics
  • Social Features:
    • Friend system with invitations
    • Group Bible study sessions
    • Messaging and prayer requests
    • Session logging and sharing
  • Study Tools:
    • Word search and concordance
    • Cross-references and related verses
    • Session history and analytics
    • Customizable reading settings

Domain Concepts

  • Bible Data:
    • BibleVersionId: "niv" | "kjv"
    • BibleCursor: Navigation position in Bible
    • BibleBookEnum: All 66 books of the Bible
    • Strong's Numbers: Greek/Hebrew word references
  • User Management:
    • User authentication via Convex Auth
    • User profiles and usernames
    • Friendship system
    • Group membership and roles
  • Study Features:
    • Memory verses with practice tracking
    • Session logging for study analytics
    • Verse ranges and selections
    • Study progress and statistics
